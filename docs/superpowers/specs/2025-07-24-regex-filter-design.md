# 正则过滤管理功能设计

## 概述

在跟打器设置页新增"过滤"分类，让用户配置文章内容的关键词替换、正则替换和黑名单屏蔽规则。规则对文来、本地发文、练单器、剪贴板可选生效，对赛文永远不生效。

## 1. 数据模型与存储

### 配置键

通过现有 `Config` 类存储在 `config.txt` 中：

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `过滤_生效_文来` | `是` | 文来模式是否启用过滤 |
| `过滤_生效_本地发文` | `是` | 本地发文是否启用过滤 |
| `过滤_生效_练单器` | `否` | 练单器是否启用过滤 |
| `过滤_生效_剪贴板` | `否` | 剪贴板载文是否启用过滤 |
| `过滤_文来最大重试` | `5` | 文来遇到黑名单自动换下一条的上限 |
| `过滤_黑名单关键词` | 见下方默认值 | 换行分隔，一行一条 |
| `过滤_替换关键词` | 见下方默认值 | 换行分隔，`旧词=>新词` 格式 |
| `过滤_黑名单正则` | 见下方默认值 | 换行分隔，一行一条正则 |
| `过滤_替换正则` | 空 | 换行分隔，`pattern=>replacement` 格式 |

多行文本在 config.txt 中用 `\n` 转义存储，读取时还原为换行。

### 默认值（来自服务端规则）

**替换关键词**（12条，来自服务端 contentReplaceRules）：
```
（求全订）
（校对版全本）
[四月天VIP完结]
[新浪vip完结]
　——晋江原创网[作品库]
（V文完结）
[潇湘vip完结]
[红袖vip完结]
[腾讯vip完结]
[起点vip完结]
（精校版全本）
（实体版全本）
```
省略 `=>` 表示替换为空（即删除）。

**黑名单正则**（5条，由服务端 contentBlacklistRules 的连续字符规则转换）：
```
。{7,}
={5,}
——{3,}
—{5,}
。{5,}
```

**黑名单关键词**：默认为空（服务端的书名黑名单如"网游""NBA"等是针对书名的，跟打器这边过滤的是文章内容，不适用）。

### RegexFilter 类

新增 `Article/RegexFilter.cs`，职责：

- 解析规则文本为内存中的规则列表
- 提供 `FilterResult Apply(string text, string source)` 方法
  - `source` 参数标识来源（文来/本地发文/练单器/剪贴板），用于检查对应的生效开关
  - 返回 `FilterResult`：过滤后文本 + 是否命中黑名单 + 命中详情列表（用于预览高亮）
- 执行顺序：先替换（关键词 → 正则），再检查黑名单（关键词 → 正则）
- 正则编译失败时静默跳过该条规则，不影响其他规则

```csharp
public class FilterResult
{
    public string Text { get; set; }           // 过滤后的文本
    public bool IsBlocked { get; set; }        // 是否命中黑名单
    public string BlockReason { get; set; }    // 命中的黑名单规则描述
    public List<FilterDiff> Diffs { get; set; } // 替换差异列表（用于预览）
}

public class FilterDiff
{
    public int Position { get; set; }    // 原文中的位置
    public string Original { get; set; } // 原文内容
    public string Replaced { get; set; } // 替换后内容
}
```

## 2. 过滤执行流程

### 文来（ArticleSender/）

在 `ArticleFetcher` 获取到文章内容后、交给主界面之前调用 `RegexFilter.Apply()`：
- 命中黑名单：自动请求下一条，计数器 +1
- 达到最大重试次数仍命中：弹出提示"连续 N 篇文章被过滤规则屏蔽，请检查过滤设置或换个分类"，本次不加载文章
- 替换规则正常执行，替换后的文本作为最终文章内容

### 本地发文（Article/）

在 `ArticleManager` 加载文章内容后调用 `RegexFilter.Apply()`：
- 命中黑名单：跳过该文章，自动加载下一篇（同样有重试上限和失败提示）
- 替换正常执行

### 练单器（WinTrainer/）

在练单器加载练习内容后调用 `RegexFilter.Apply()`：
- 命中黑名单：提示用户该内容被屏蔽
- 替换正常执行

### 剪贴板载文

在剪贴板文本载入后调用 `RegexFilter.Apply()`：
- 逻辑同练单器

### 赛文

不调用过滤，完全跳过。

### 生效开关检查

每个接入点调用前先检查对应的 `过滤_生效_xxx` 配置，关闭则跳过整个过滤流程。

## 3. 设置页 UI

在 `WinConfig` 的 `_categories` 中新增 `"过滤"` 分类，插在"赛文"和"成绩"之间。

### 布局（从上到下）

**3.1 生效范围**

四个勾选框横排：
- `文来` ☑（默认勾选）
- `本地发文` ☑（默认勾选）
- `练单器` ☐（默认不勾选）
- `剪贴板` ☐（默认不勾选）

下方灰色小字：`赛文始终不受过滤影响`

**3.2 文来最大重试次数**

标签 + 数字输入框，默认 5，范围 1-50。
提示文字：`文来遇到被屏蔽的文章时，自动换下一篇的最大次数`

**3.3 简单模式**

小标题：`关键词（普通用户推荐）`

两个多行文本框纵向排列：

- **屏蔽关键词**
  - 标签 + 多行 TextBox
  - Placeholder: `一行一个，包含该词的文章将被跳过`
  
- **替换关键词**
  - 标签 + 多行 TextBox
  - Placeholder: `格式：旧词=>新词（省略=>新词则删除该词）`

**3.4 高级模式**

小标题：`正则表达式（进阶用户）`

两个多行文本框纵向排列：

- **屏蔽正则**
  - 标签 + 多行 TextBox
  - Placeholder: `一行一条正则，匹配到的文章将被跳过`

- **替换正则**
  - 标签 + 多行 TextBox
  - Placeholder: `格式：正则=>替换内容`

**3.5 配置参考说明**

灰色文字块，内容：

```
【关键词说明】
• 一行一个关键词
• 屏蔽：包含该关键词的文章会被跳过
• 替换：旧词=>新词，省略=>新词则删除该词
• 例：（求全订）     → 删除所有"（求全订）"
• 例：旧词=>新词     → 把"旧词"替换成"新词"

【正则说明（进阶）】
• 一行一条正则表达式
• 。{7,}            → 匹配连续7个以上的句号
• \d{3,}            → 匹配3位以上的数字
• [a-zA-Z]+         → 匹配英文单词
```

**3.6 效果预览**

小标题：`效果预览`

- 一个多行输入框：用户粘贴测试文本
- 下方显示过滤结果：
  - 被替换的部分：红色删除线标出原文 + 绿色显示替换后文字
  - 命中黑名单：整块红色背景提示"该文本命中屏蔽规则：xxx"
- 输入框内容变化时实时更新预览（加 300ms 防抖）

### UI 实现方式

由于"过滤"分类的内容不是简单的 key-value 配置项，不适合用现有的 `ShowCategory` + `CreateValueControl` 逻辑。采用与"成绩"分类类似的方式：在 `ShowCategory` 中检测到 `category.Title == "过滤"` 时，调用专门的 `AppendFilterSettings(currentRow)` 方法来构建自定义 UI。
