# 晴练单主窗口单独记忆设计

## 背景

主窗口现在只有一套全局窗口和布局配置。`Config/Config.cs` 中保存窗口宽高、坐标、首页按钮显示、成绩区展开、发文区/跟打区比例、成绩区比例和一键极简状态。`UI/MainWindow.xaml.cs` 中的窗口加载、尺寸变化、分隔条拖动、首页按钮刷新和一键极简逻辑都直接读写这些全局键。

晴练单通过 `WinTrainer` 调用 `MainWindow.LoadText(..., TxtSource.trainer, ...)` 把练单文本送入主窗口。用户希望练单场景下主窗口可以使用独立的布局偏好，离开练单后恢复普通主窗口偏好，避免练单时调整一键极简、隐藏按钮或拖动高度污染平时跟打布局。

## 目标行为

1. 晴练单中新增“主窗口单独记忆”开关，默认打开。
2. 开关打开时，主窗口加载 `TxtSource.trainer` 文本后进入练单场景配置作用域。
3. 进入练单场景时，主窗口自动切换到练单场景下记忆的模式、尺寸和布局。
4. 主窗口加载非练单文本后退出练单场景配置作用域，自动切回普通主窗口配置。
5. 开关打开时，练单场景下这些调整单独记忆：
   - 一键极简开关。
   - 一键极简后的窗口高度。
   - 首页/主窗口功能按钮显示和顺序。
   - 成绩面板展开/收起。
   - 主窗口宽度、高度、坐标。
   - 发文区/跟打区比例和成绩区高度比例。
   - 展开窗口高度等成绩区展开辅助值。
6. 晴练单中新增“重置主窗口记忆”功能，清空练单场景专用主窗口配置；开关本身不被重置。

## 非目标

- 不改变晴练单窗口自身的尺寸、字体、统计和发文后关闭窗口记忆。
- 不改变普通主窗口配置文件格式。
- 不新增独立配置文件；练单场景配置仍写入现有 `config.txt`。
- 不改变 `TxtSource.trainer` 的成绩统计、字数统计和发文逻辑。
- 不把“打开晴练单窗口但还没有加载练单文本”视为进入练单场景。

## 场景边界

进入练单场景的唯一业务边界是主窗口加载 `TxtSource.trainer` 文本：

- `WinTrainer.LoadText(...)`
- `WinTrainer.BtnSend_Click(...)`
- 练单中重打、乱序、自动推进等再次调用 `MainWindow.LoadText(..., TxtSource.trainer, ...)` 的路径

退出练单场景的边界是主窗口加载任何非 `TxtSource.trainer` 且非 `TxtSource.unchange` 的文本，例如文来、本地文章、剪贴板、群载文、赛文等。单纯关闭或隐藏晴练单窗口不触发退出，因为主窗口仍可能停留在练单文本。

## 设计

采用“练单场景配置作用域”而不是复制主窗口布局逻辑。主窗口继续通过现有代码刷新首页按钮、一键极简、尺寸和分隔条比例，但读写配置时根据当前作用域选择普通键或练单专用键。

新增一个小型 helper，例如 `TrainerMainWindowConfigScope` 或等价方法，负责三件事：

- 判断练单单独记忆是否启用。
- 把需要隔离的普通配置键映射到练单专用配置键。
- 提供进入、退出、重置和按作用域读写配置的方法。

当开关关闭时，所有读写都使用普通全局键，行为与当前版本一致。

如果用户在主窗口当前已经处于练单场景时关闭开关，主窗口应先保存当前练单专用状态，然后立即退出练单配置作用域并应用普通主窗口配置。再次打开开关时，如果当前主窗口文本来源仍是 `TxtSource.trainer`，主窗口应立即进入练单配置作用域并应用练单专用配置。

## 配置键

新增普通布尔键：

- `练单主窗口单独记忆`，默认 `是`。

新增练单场景专用键，使用 `练单场景_` 前缀：

- `练单场景_窗口高度`
- `练单场景_窗口宽度`
- `练单场景_窗口坐标X`
- `练单场景_窗口坐标Y`
- `练单场景_一键极简`
- `练单场景_一键极简后窗口高度`
- `练单场景_成绩面板展开`
- `练单场景_展开窗口高度`
- `练单场景_发文区跟打区比例`
- `练单场景_成绩区高度比例`
- `练单场景_首页功能按钮顺序`
- `练单场景_显示首页文来`
- `练单场景_显示首页练单`
- `练单场景_显示首页晴双拼`
- `练单场景_显示首页赛文`
- `练单场景_显示首页设置`
- `练单场景_显示首页本地文章`
- `练单场景_显示首页重打`
- `练单场景_显示首页剪贴板载文`
- `练单场景_显示首页群载文`
- `练单场景_显示首页选群`

练单专用键没有值时，读取普通键作为初始值。这样用户第一次进入练单场景时会继承当前主窗口布局，之后才独立变化。

## 主窗口切换流程

`MainWindow.LoadText(...)` 设置文本来源后调用场景同步方法：

1. 如果目标来源是 `TxtSource.trainer`，且开关打开：
   - 如果当前不在练单配置作用域，先保存普通作用域当前窗口状态。
   - 切换到练单配置作用域。
   - 应用练单场景配置到主窗口，包括窗口大小、坐标、一键极简、首页按钮、成绩区和比例。
2. 如果目标来源是非练单且非 `TxtSource.unchange`：
   - 如果当前在练单配置作用域，先保存练单作用域当前窗口状态。
   - 切回普通配置作用域。
   - 应用普通配置到主窗口。
3. 如果目标来源是 `TxtSource.unchange`，不改变作用域。

重复加载练单文本时不反复切换作用域，只保持练单配置并继续正常载文。

## 状态保存

现有保存点改为使用作用域键：

- `RunWindowResizeCompletedWork()` 保存窗口宽度、高度和一键极简后高度。
- 主窗口关闭时保存窗口坐标和当前作用域下的窗口状态。
- 分隔条拖动完成后的 `SaveDisplayInputRatio()` 保存发文区/跟打区比例和成绩区比例。
- 成绩区展开/收起保存 `成绩面板展开` 和 `展开窗口高度`。
- 首页按钮显示、排序和一键极简切换保存到当前作用域。

保存坐标时只在窗口正常显示、尺寸合理时写入，避免最小化或异常位置污染配置。

## 应用状态

主窗口切换作用域后需要刷新这些 UI：

- 窗口宽度、高度和坐标。
- 首页顶部按钮和底部功能按钮排序/可见性。
- 一键极简布局。
- 成绩区展开/收起布局。
- 发文区/跟打区/成绩区比例。
- 右键菜单中的一键极简勾选和成绩区展开状态。

刷新应使用现有 `ApplyHomeToolbarSettings()`、`ApplySuperCompactModeLayout(...)`、`ApplyDisplayInputRatio()`、成绩区展开/收起 helper 等路径，减少重复逻辑。

## 晴练单 UI

在 `WinTrainer.xaml` 工具栏或设置区域加入：

- `CheckBox`：文案 `主窗口单独记忆`。
- `Button`：文案 `重置主窗口记忆`。

加载晴练单窗口时，勾选状态从 `Config.GetBool("练单主窗口单独记忆")` 读取。勾选变化立即写入 `Config`。

勾选变化后通知当前主窗口重新同步练单配置作用域：

- 当前主窗口来源是 `TxtSource.trainer` 且开关打开：进入练单配置作用域。
- 当前主窗口来源是 `TxtSource.trainer` 且开关关闭：退出练单配置作用域并回到普通配置。
- 当前主窗口来源不是 `TxtSource.trainer`：只保存开关，不改变主窗口作用域。

点击重置按钮时：

1. 弹出确认：`确定要清空练单场景下的主窗口记忆吗？`
2. 确认后移除或清空所有 `练单场景_` 专用键。
3. 保留 `练单主窗口单独记忆` 当前值。
4. 如果主窗口当前处于练单配置作用域，立即按“无练单专用值”的规则重新应用一次，使它回到继承普通配置的状态。

## 错误处理

- 练单专用尺寸值无效时回退普通主窗口值。
- 普通主窗口值也无效时沿用当前主窗口默认尺寸逻辑。
- 练单专用按钮顺序无效时走 `HomeToolbarSettings.NormalizeFeatureOrder(...)`。
- 切换作用域期间抑制窗口尺寸变化保存，避免刷新 UI 的中间尺寸写入配置。

## 设置页联动

设置页已经可以修改首页按钮显示和排序。练单场景单独记忆打开且主窗口处于 `TxtSource.trainer` 时，设置页中首页按钮相关项也应写入练单作用域键；否则用户在练单中通过设置页隐藏主窗口按钮仍会污染普通配置。

设置页不需要展示两套配置。它只编辑“当前主窗口作用域”的值：

- 普通场景下编辑普通配置。
- 练单场景且开关打开时编辑练单专用配置。
- 练单场景但开关关闭时编辑普通配置。

优先添加静态 PowerShell 回归测试，覆盖关键接线：

- `Config` 默认包含 `练单主窗口单独记忆 = 是`。
- 存在练单场景配置键映射 helper。
- `MainWindow.LoadText(...)` 在设置 `StateManager.txtSource` 后调用练单场景同步方法。
- `RunWindowResizeCompletedWork()` 使用作用域键保存窗口尺寸和一键极简高度。
- `SaveDisplayInputRatio()` 使用作用域键保存比例。
- 首页按钮和一键极简读写使用作用域键。
- 设置页首页按钮保存路径使用当前主窗口作用域键。
- `WinTrainer.xaml` 包含 `主窗口单独记忆` 开关和 `重置主窗口记忆` 按钮。
- `WinTrainer.xaml.cs` 勾选变化写入 `练单主窗口单独记忆`，重置调用清空练单专用键。

如果可拆出纯逻辑 helper，则增加 C# 单元测试覆盖：

- 开关关闭时映射返回原始键。
- 开关打开且处于练单作用域时映射返回 `练单场景_` 键。
- 练单专用值缺失时读取普通键。
- 重置只清空 `练单场景_` 键，不清空开关键。

## 风险

- `MainWindow.xaml.cs` 中直接读写 `Config` 的位置很多，遗漏某个保存点会导致练单调整污染普通配置。
- 一键极简已有独立高度记忆，切换作用域时要保持“极简高度”和“普通高度”继续分开，不能让极简恢复时覆盖普通高度。
- 进入/退出作用域时会触发布局和窗口尺寸变化，必须用现有抑制机制避免中间状态被保存。
- 如果用户在练单场景中打开设置页修改首页按钮，设置页也需要写入当前作用域，否则会和主窗口右键菜单/按钮行为不一致。
